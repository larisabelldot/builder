# Lana Del Rey Song Guessing Game

A beautiful, interactive web game to test your knowledge of Lana Del Rey's discography.

## Features

- **5-Second Song Clips**: Listen to a short clip from YouTube and guess the song
- **Modern Countdown Timer**: Animated circular countdown with gradient effects
- **30 Songs**: Extensive library covering Lana's entire career
- **Vintage Aesthetic**: Dreamy, romantic design inspired by Lana's visual style
- **Score Tracking**: See how well you know the queen of sadcore
- **Personalized Messages**: Get themed messages based on your final score

## How to Play

1. Open `index.html` in your browser
2. Click "Begin the Journey" to start
3. Click "Play Clip" to hear a 5-second snippet
4. Choose the correct song from 4 options
5. Complete all 10 rounds to see your final score

## Technical Details

- Pure HTML, CSS, and JavaScript
- Uses YouTube IFrame API for video playback
- Responsive design for mobile and desktop
- No external dependencies (except Google Fonts)
